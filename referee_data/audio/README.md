# 本機音效，不隨 repo 發布

本目錄不附 WAV，也不會自動下載音檔。未提供音檔時，裁判頁會明確提示；勾選「靜音」仍可開始比賽。

如有使用許可，可自行在本機放入 `start.wav`、`resume.wav`、`end.wav`、`abort.wav`，再執行裁判角色的 `buildfs`／`uploadfs`。這四個名稱是播放介面，不表示任何錄音自動取得 FRC 原版身分。原版來源的使用範圍須另行確認；也可以使用自行錄製或具有適當授權的替代錄音，並向裁判說明版本。

`.gitignore` 排除本目錄的 WAV；不得以 `git add -f` 加回。含有錄音的 LittleFS 映像同樣不得在未取得轉散布許可時發布。

`manifest.json` 只保留曾核對的 Team 254 來源版本、檔名與雜湊，作為歷史來源紀錄，**不授予使用或轉散布權利**。`LICENSE.txt` 是當時上游授權原文的留存，並非本專案音效授權。該文字允許特定用途的使用，並列出貢獻回原專案的轉散布情境；本專案未取得另外的轉散布許可，因此移除原音檔。

舊公開提交 `fd2c132` 曾包含錄音；本次移除只影響新版本，不代表 Git 歷史、既有下載或其他副本已清除。
