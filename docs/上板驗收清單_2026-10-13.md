## 5. 內建上拉（INPUT_PULLUP）

| # | 步驟 | 預期 | 結果 |
|---|------|------|------|
| 5.1 | 開關接 GPIO 15 ↔ GND（不接電阻），跑 13-digital-input | 放開時舵機 0°、按下 90°，放開不亂跳 | |
| 5.2 | 把 setup 的「設定腳位」改成 INPUT 再跑 | 放開時讀值可能亂跳（對照組，證明上拉有作用） | |
| 5.3 | 再送一支沒有「設定腳位」的程式讀 GPIO 15 | 不沿用上一支的上拉（每支新程式清空） | |

## 6. I2C 從機（需 i2cESP32 主機）

先改燒 I2C 版：`pio run -e esp32dev_i2c --target upload`（SDA 21 / SCL 22，位址 0x36）。

| # | 步驟 | 預期 | 結果 |
|---|------|------|------|
| 6.1 | 跑 41-i2c-param-in，主機改設定值 | 舵機約即時跟著動 | |
| 6.2 | 跑一支「前進 5 秒」的程式（pwm + delay 5000），途中主機送 STOP_ALL | 馬達**立即**停（不必等 5 秒），程式也停了：不會在 delay 結束後又動 | |
| 6.3 | 沒有程式在跑時主機送 STOP_ALL | 不出錯；舵機不會自己跳回 90° | |
| 6.4 | 跑 42-i2c-report，主機讀回距離 | 讀到的值與 Plotter／訊息一致 | |
| 6.5 | 程式在 `while` 等待 `讀取對外功能 = 1` 時，主機設值為 1 | 迴圈立刻結束、往下執行（舊版會永遠等） | |
