# 📱 ESP32 機器人控制器操作說明

## 🏠 主頁面 (index.html)

### 頁面功能
ESP32 機器人控制系統的首頁，提供各功能模組的入口。

### 操作步驟
1. **系統啟動**
   - 確保 ESP32 已開機
   - 連接到 ESP32 的 WiFi 熱點或確保在同一網路
   - 在瀏覽器輸入 ESP32 IP 位址

2. **功能選擇**
   - 🧩 **積木程式設計**：點擊進入 Blockly 視覺化程式設計
   - 🎮 **手動控制**：進入搖桿控制模式
   - 🔧 **硬體檢測**：進入硬體功能測試
   - ⚙️ **系統設定**：修改 WiFi 和控制板設定

## 🧩 積木程式設計頁面 (blockly.html)

### 頁面功能
使用拖拉積木的方式設計機器人程式，支援馬達控制、感測器讀取、邏輯運算等。

### 操作步驟

#### 📝 程式設計
1. **積木操作**
   - 從左側工具箱拖拉積木到中央工作區
   - 將積木組合成完整程式
   - 使用 `arduino_setup` 作為程式起點
   - 使用 `arduino_loop` 建立重複執行的程式

2. **常用積木分類**
   - **Arduino**：基本程式結構
   - **馬達控制**：M1、M2 馬達速度控制
   - **伺服馬達**：角度控制
   - **感測器**：超音波、數位/類比讀取
   - **流程控制**：如果、重複 N 次、當／直到重複（可互相包，最多 8 層；迴圈裡需要間隔請加延遲）
   - **數學**：加減乘除、餘數、絕對值、隨機整數、限制範圍、對應換算（例：距離 0–100 cm 換成角度 0–180°）；都是整數運算
   - **邏輯**：比較、且／或、真假、反相
   - 馬達、舵機、延遲的數值格子可以直接填數字，也可以拖進變數或算式（例如角度 = i × 10）
   - 沒接在 setup／loop 裡的積木不會執行，按執行時會提示
   - **副程式**：把常用動作包起來重複使用；點副程式積木左上角齒輪可加參數。副程式不能呼叫自己
   - **數學**：運算、比較
   - **變數**：資料儲存

#### 📱 畫面怎麼排的（2026-10-10 改版）

整頁**不會上下捲動**，畫面固定分成四條：

```
頂列    🧩 積木程式設計        ⤢ 看全部  ⇅  ☰
────────────────────────────────────────────
         積木工作區（唯一會動的區域）
────────────────────────────────────────────
訊息列  📱 最新一條訊息                     ▾
底列         ⏹️ 停止            ▶️ 執行
```

改成這樣的原因：舊版是一個長頁面、積木區只是中間一個固定高度的視窗，結果
頁面和積木畫布都會動、手指在畫布邊緣一拖就分不清是要平移畫布還是捲頁面；
而且一捲頁面，正在編輯的工作區就有一半跑出螢幕。現在唯一會動的只有畫布。

#### 🎮 程式執行
1. **執行程式**
   - 點擊畫面**底部**的「▶️ 執行」（手機上拇指最好按的位置，而且編輯時永遠看得到）
   - 看訊息列的回應；要看完整紀錄點一下訊息列展開

2. **看不到整支程式時**（手機上最常遇到）
   - **⤢ 看全部**：把整支程式縮到剛好塞滿畫面，這是最快的一招
   - **⇅**：先把散落各處的積木排成一直欄，再自動「看全部」
   - 也可以**兩指縮放**畫布（這功能本來就有，只是沒人知道）

3. **程式控制**
   - **⏹️ 停止**：立即停止執行（底列左邊）
   - **🏠 停止程式並回首頁**：在 **☰** 選單裡

4. **檔案管理**（**☰** 選單 →「程式操作」，分成 ESP32 與本機兩組）
   - **💾 存到 ESP32**：存到板子上。板子**只存一支**，開機自動執行就是跑這支；
     板子上已有別的程式時會先問是否覆蓋（想保留就先「從 ESP32 開啟」再「下載到本機」）
   - **📂 從 ESP32 開啟**：讀回板子上那一支；打開積木頁時也會自動載入
   - **⬇️ 下載到本機**：存成 `.xml` 檔到電腦或手機的下載資料夾，可自己取檔名，用來備份或分享給同事
   - **⬆️ 從本機開啟**：選一個 `.xml` 檔載入（電腦、手機都可以）。只是開到畫面上，
     要在板子上執行或開機自動跑，還要再按「存到 ESP32」
   - **⚡ 開機自動執行**：也在這一組裡（autorun 跑的就是板子上那一支）
   - 檔案操作按完選單會自動收起來，免得結果訊息被選單蓋住
   - 畫面上有還沒存的修改時，開啟任何程式前都會先確認，避免蓋掉
   - 含舊版「馬達」「舵機」積木的舊檔案已無法開啟

#### 💡 訊息列
- 收起來時只有一行，顯示**最新一條**訊息；點一下展開成完整面板（最多保留 10 條）
- 內容包含 WebSocket 連線狀態、ESP32 回應、程式執行結果、感測器數據
- 錯誤訊息要在編輯時就看得到才有用，所以它固定在畫面內、不會被捲走

### 📋 使用提示
1. 先設計完整程式再執行
2. 注意 WebSocket 連線狀態
3. 適時存檔；重要的程式另外「下載到本機」備份（板子上只有一支）
4. 觀察訊息列了解執行狀態
5. **手機上寫大程式會很擠**，這是 390px 寬螢幕的物理限制。建議手機當現場操作與
   微調的介面，大程式在平板或電腦上寫完「下載到本機」存成 `.xml`，再帶到手機
   「從本機開啟」。單純要驗證機械行為的話，`joy.html` 搖桿頁和
   `hardware_test.html` 比積木頁更合適

## 🎮 手動控制頁面 (joy.html)

### 頁面功能
提供即時的搖桿控制介面，可直接操控機器人移動和功能。

### 操作步驟

#### 🕹️ 搖桿控制
1. **左搖桿**：控制機器人移動方向
   - 上下：前進/後退
   - 左右：左轉/右轉

2. **右搖桿**：控制伺服馬達
   - S1、S2 伺服馬達角度調整

#### 🎛️ 按鈕控制
1. **功能按鈕**
   - **Button1/Button2**：自訂功能按鈕
   - **Action3/Action4**：動作控制

2. **滑桿控制**
   - 調整伺服馬達角度
   - 即時反應控制

#### 📊 狀態顯示
- 即時顯示控制狀態
- 電壓監控
- 連線狀態指示

### 📋 使用提示
1. 確保 WebSocket 連線正常
2. 操作前檢查機器人狀態
3. 注意安全距離和環境

## 🔧 硬體檢測頁面 (hardware_test.html)

### 頁面功能
系統化檢測機器人各項硬體功能，產生檢測報告。

### 操作步驟

#### 🎯 檢測項目選擇
1. **選擇檢測項目**
   - ⚙️ M1 馬達測試
   - ⚙️ M2 馬達測試
   - 🔘 LEGO 按鈕 (GPIO 4)
   - 📐 超音波測距 (Trig:2/Echo:33)
   - 📱 數位讀值 (GPIO 15)
   - 📊 類比讀值 (GPIO 32)

2. **檢測模式選擇**
   - **🚀 自動檢測**：依序執行所有選中項目
   - **👆 手動檢測**：逐項手動執行

#### 🔍 執行檢測

**自動模式：**
1. 勾選要檢測的項目
2. 點擊「🚀 開始自動檢測」
3. 系統依序執行各項測試
4. 根據提示進行操作確認

**手動模式：**
1. 點擊「👆 切換到手動模式」
2. 逐一點擊各項目的測試按鈕
3. 觀察測試過程和數值變化
4. 確認測試結果

#### 📋 各項測試詳細說明

**M1/M2 馬達測試：**
- 自動執行正轉、反轉、停止序列
- 觀察馬達轉動是否正常
- 點擊「是」或「否」確認結果

**LEGO 按鈕測試：**
- 監測 GPIO 4 的數值變化
- 測試期間按下並鬆開按鈕
- 系統檢測數值變化確認功能

**超音波測距測試：**
- 讀取距離數據 (單位：公分)
- 用手掌在感測器前方移動
- 觀察距離數值隨動作變化

**數位讀值測試：**
- 讀取 GPIO 35 的數位值 (0/1)
- 顯示 HIGH/LOW 狀態
- 記錄初始值和變化

**類比讀值測試：**
- 讀取 GPIO 34 的類比值 (0-4095)
- 顯示數值和百分比
- 監測類比信號變化

#### 📊 檢測報告
1. **即時顯示**
   - 當前數值即時更新
   - 測試狀態顏色指示
   - 測試進度追蹤

2. **匯出報告**
   - 點擊「📄 匯出檢測報告」
   - 下載包含所有測試結果的文字檔
   - 報告包含設備資訊和測試統計

### 📋 使用提示
1. 檢測前確保硬體連接正常
2. 按照提示進行相應操作
3. 仔細觀察數值變化
4. 及時儲存檢測報告

## ⚙️ 系統設定頁面 (set.html)

### 頁面功能
設定 WiFi 連線和控制板名稱，支援靈活的設定選項。

### 操作步驟

#### 🔧 設定項目選擇
1. **選擇要修改的項目**
   - ☑️ **修改 WiFi 連線設定**：更改網路連線
   - ☑️ **修改控制板名稱**：更改 AP 熱點名稱
   - 可單選或同時選擇

2. **動態介面提示**
   - 根據選擇自動顯示相關欄位
   - 即時更新操作說明
   - 按鈕文字自動調整

#### 📡 WiFi 設定 (當選擇 WiFi 設定時)
1. **WiFi SSID**：輸入要連接的網路名稱
   - 預設值：`fssh`
2. **WiFi 密碼**：輸入網路密碼
   - 預設值：留空（請自行填入，勿提交真實密碼）

#### 🏷️ 控制板名稱設定 (當選擇名稱設定時)
1. **控制板(AP)名稱**：設定熱點名稱
   - 預設為：ESP32-末四碼
   - 自訂名稱方便識別

#### 🔐 安全驗證
1. **管理密碼**：輸入管理密碼
   - 預設密碼：`123456`
   - 防止未授權修改

#### 💾 儲存設定
1. **確認設定**
   - 檢查輸入資料是否正確
   - 點擊對應的儲存按鈕
   - 等待系統重啟完成

2. **按鈕說明**
   - **儲存 WiFi 與名稱設定**：同時更新兩項
   - **儲存 WiFi 設定**：僅更新網路設定
   - **儲存控制板名稱**：僅更新 AP 名稱

### 📋 重要注意事項
1. **設定後重啟**：儲存後 ESP32 會自動重啟
2. **連線變更**：WiFi 設定變更後需重新連接
3. **設定備份**：建議記錄設定內容
4. **網路環境**：確保目標 WiFi 網路可用

## 🔄 換控制器：複製調校參數（桌面調校工具）

> ⚠️ 本節操作不在控制器網頁，而在電腦上的桌面程式「**phone_blocky 馬達調校工具**」（`motor_tuner`）。

作為課堂教具，常需要「燒一塊新板 → 改名 → 把已調好那塊板的參數搬過來」。
調校工具「**設定**」分頁左欄提供參數檔匯出／匯入：

1. **匯出**：連線已調好的板子 → 按「**匯出參數**」存成 `.json`（建議當標準參數範本保存）。
2. **匯入**：連線新板 → 按「**匯入並寫入NVS**」選該 `.json`，即把馬達參數寫入新板的 NVS（不重啟）。

重點：

- 匯出／匯入**只含馬達參數**（PID、前饋、硬體種類、角度保持），**不含 WiFi 與板名**，
  所以每塊板都保留自己唯一的板名，複製參數不會讓全班同名。
- 建議順序：**先改名／設 WiFi（會重啟）→ 重連 → 再匯入參數（不重啟）**。
- 完整圖文步驟見 [安裝教程 — 換板：複製調校參數到新控制器](安裝教程.md#換板複製調校參數到新控制器)。

## 🚨 常見問題與故障排除

### 連線問題
1. **WebSocket 未連接**
   - 檢查網路連線
   - 重新整理頁面
   - 重啟 ESP32

2. **找不到 ESP32**
   - 確認 ESP32 開機狀態
   - 檢查 WiFi 連線
   - 確認 IP 位址正確

### 硬體問題
1. **馬達不轉動**
   - 檢查電源供應
   - 確認接線正確
   - 使用硬體檢測功能

2. **感測器無回應**
   - 檢查 GPIO 接線
   - 確認感測器供電
   - 查看系統訊息錯誤

### 程式問題
1. **積木程式無效**
   - 檢查積木連接
   - 確認程式邏輯
   - 查看執行錯誤訊息

2. **控制無反應**
   - 確認 WebSocket 連線
   - 檢查控制指令
   - 重新載入頁面
