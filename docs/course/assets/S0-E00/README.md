# S0-E00 圖片素材

這組圖片配合 [`S0-E00｜這門課會給你什麼`](../../scripts/S0-E00-這門課會給你什麼.md) 使用。統一採深藍近黑背景，以及綠、藍、紫、橘、白的課程色。

| 檔案 | 建議用途 | 注意事項 |
|---|---|---|
| `01-成果主視覺.png` | 開場定格、縮圖底圖 | 實際手機操作與馬達動作應以真機拍攝 |
| `02-工具阻力對比.png` | 說明傳統工具阻力與手機操作的差異 | 畫面中的介面與電路板都是概念示意 |
| `03-五站學習路線.png` | 「動、準、穩、判、交」總覽 | 中文字請在剪輯軟體後製疊加 |
| `04-完整與最小套件.png` | 完整採買與最小可跑方案對照 | 不作為料件型號、數量核對或接線依據；採買以 BOM 為準 |

## 生成規格

- 工具：內建 ImageGen
- 比例：16:9
- 共同風格：深藍近黑攝影棚、寫實 3D 教學視覺、綠色成功燈、無品牌標誌與浮水印
- 文字：除成果圖中的角度數值外，其餘不在圖片內生成；標題與中文標籤由後製加入

## 剪輯建議

- 圖片只用來補充抽象概念，不取代真機操作、真實料件特寫或接線畫面。
- 靜態圖可做 3%–5% 的慢速推近，單張停留約 3–5 秒。
- `03-五站學習路線.png` 可由左至右依序遮罩揭露五個節點，並分別疊上「動、準、穩、判、交」。
