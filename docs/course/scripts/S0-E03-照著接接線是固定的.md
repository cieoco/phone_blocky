# S0-E03｜照著接：接線是固定的

**片長目標**：8–10 分鐘
**這集的一句話**：這塊板的腳位是寫死的，你只需要照著抄，不需要設計。

---

## 前提

- 韌體已燒錄，手機看得到 `ESP32-` 熱點（E02）

## 器材

全部零件 + 外接電源 + 超音波分壓用的 1kΩ / 2kΩ

---

## 旁白要點

### 1. 先講一件會讓人鬆一口氣的事（0:00–1:00）

> 「你不用決定任何一根線要接哪裡。腳位是寫死在韌體裡的。」
> 「這代表兩件事：第一，你不會接錯設計；第二，如果不動，**一定是接錯位置或沒接牢**，
> 不會是『我這樣設計不對』。」

> 「所以這一集你只要做一件事：照著抄。」

**畫面**：打開板子上的 [接線說明頁]（`wiring.html`）——**接線圖就在板子裡**，
不用另外找檔案、不用印紙本。（雖然現在還沒連上，先預告。）

### 2. 馬達（1:00–3:00）

樂高 RJ12 的 **白 = MA0、黑 = MA1**，接到馬達驅動板的 OUT1 / OUT2。

| 馬達 | 有編碼器 | 你能對它下什麼指令 |
|---|---|---|
| M1 | ✗ | 只能 PWM |
| M2 | ✗ | 只能 PWM |
| M3 | ✓ | PWM + 角度 + 轉速 |
| M4 | ✓ | PWM + 角度 + 轉速 |

> 「**把有編碼器的樂高馬達接在 M3 和 M4**。這門課後面所有精華——角度、閉迴路、
> 調 PID——都只在 M3、M4 上做得到。」

### 3. 樂高線色的陷阱 🚨（3:00–4:30）

**畫面**：把 RJ12 的六條線一條一條拉出來，特寫顏色。

> 「這裡有一個會害人的地方。看這條**紅線**——你以為它是電源對不對？」
>
> 「**它是接地。綠色那條才是電源。**」

| Pin | 線色 | 訊號 |
|---|---|---|
| 1 | ⬜ 白 | MA0 → 驅動板 OUT1 |
| 2 | ⬛ 黑 | MA1 → 驅動板 OUT2 |
| 3 | 🟥 **紅** | **GND** ← 不是電源 |
| 4 | 🟩 **綠** | **VCC 4.3–5V** ← 這條才是 |
| 5 | 🟨 黃 | A 相 → M3: GPIO **35** / M4: GPIO **36** |
| 6 | 🟦 藍 | B 相 → M3: GPIO **34** / M4: GPIO **39** |

> 「接反了編碼器不會動，嚴重一點會燒。這是全片最需要停下來核對的地方。」

水晶頭正面（金屬片朝上、卡榫朝下）由左至右 Pin 1 → 6。

### 4. 編碼器不需要外接上拉電阻（4:30–5:00）

> 「黃線和藍線直接接到腳位就好，**不用再加任何電阻**。」

> 「樂高的編碼器是主動輸出的——高電位和低電位它自己都會拉，
> 不需要外面幫它拉住。」

> 板子內建的接線說明頁已同步這個說明，學員自己查也會看到一致的答案。

（換非樂高的編碼器就不一定了，那是 BOM § F 的進階議題，S0 不談。）

### 5. 舵機與感測器（5:00–7:00）

| 元件 | 腳位 |
|---|---|
| 舵機 S1 | GPIO **5** |
| 舵機 S2 | GPIO **13** |
| 樂高按鈕 | GPIO **4**（另一端接 **GND**） |
| 超音波 Trig | GPIO **2** |
| 超音波 Echo | GPIO **33**（⚠️ 要分壓，見下） |
| 數位輸入 | GPIO **15** |
| 類比輸入 | GPIO **32** |

**超音波 Echo 的分壓**：

```
Echo ──[ 1kΩ ]──┬── GPIO 33
                │
             [ 2kΩ ]
                │
               GND
```

> 「HC-SR04 要 5V 才動，但它吐出來的訊號也是 5V，而 ESP32 的腳不耐 5V。
> 兩顆電阻的事，別省。」

### 6. 電源（7:00–8:30）⚠️

**畫面**：把外接電源接上驅動板，並把 GND 拉到 ESP32 的 GND。

> 「ESP32 的 USB 供電**推不動馬達**。驅動板一定要外接電源。」
>
> 「電流抓 **3A 以上**。電流不夠的樣子你絕對想不到——
> 馬達抽一下就停、板子突然重開機、WiFi 斷線、編碼器數字亂跳。
> 你會以為是程式壞了，去查程式，然後查三個小時。」

> 「還有一件一定要做的事：**外接電源的 GND 要接到 ESP32 的 GND**。
> 沒有共同的地，訊號就沒有共同的參考點。」

### 7. 禁區（8:30–9:00）

**畫面**：紅色標出。

| GPIO | 狀態 |
|---|---|
| 12 14 16 17 19 23 25 27 | 🚫 馬達驅動板佔用 |
| 5 13 | 🚫 舵機 |
| 34 35 36 39 | 🚫 編碼器 |

> 「這些腳位不要外接任何東西。剩下的 2、4、15、26、32、33 才是你的。」

## 成功訊號

這集**還沒有**可觀察的電氣訊號（那是 E06 的事）。用檢查清單驗收：

- [ ] 有編碼器的馬達接在 **M3 / M4**
- [ ] RJ12 紅線接到 **GND**、綠線接到 **VCC**（核對兩次）
- [ ] 黃 → 35/36、藍 → 34/39（**直接接，不用電阻**）
- [ ] 超音波 Echo 有分壓
- [ ] 外接電源接上驅動板，**且 GND 與 ESP32 共地**
- [ ] 禁用腳位上沒有接任何東西

> 「全部打勾之前不要通電。」

---

## 常見卡點

| 症狀 | 說明 |
|---|---|
| 「線色跟影片不一樣」 | 非原廠樂高線可能不同色，以**針腳位置**為準，不要以顏色為準 |
| 「接線頁說要加上拉電阻？」 | 樂高編碼器**不用**。那句註記是針對開集極輸出的元件，樂高是主動輸出 |
| 「一定要接滿四顆馬達嗎？」 | 不用。只接 M3 一顆就能跑完 S0–S3，自檢時取消勾選其他項即可 |
| 「GPIO 2 上的 LED 一直亮/暗」 | GPIO 2 也是板載 LED，開機瞬間為低電位，正常 |
