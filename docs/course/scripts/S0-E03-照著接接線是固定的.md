# S0-E03｜照著接：接線是固定的

**片長目標**：8–10 分鐘
**這集的一句話**：帶觀眾把線接完，並說明為什麼這塊板子的接線不需要自己設計。

---

## 前提

- 韌體已燒錄，手機看得到 `ESP32-` 熱點（E02）

## 器材

- 全部零件
- 外接電源
- 超音波分壓用的 1kΩ 與 2kΩ 電阻

---

## 旁白要點

### 1. 先說明這一集要做什麼（0:00–1:00）

**畫面**：桌上零件已就位，鏡頭帶過整組線材。

> 「這一集要把線接完。開始之前先講一件事：你不需要決定任何一根線要接哪裡。」
>
> 「這塊板子的腳位是寫在韌體裡的，位置固定。這代表兩件事：第一，你不會接出一個設計上的錯誤；第二，如果之後有東西不動，原因會是接錯位置或沒接牢，而不是接法本身有問題。」
>
> 「所以這一集你只要做一件事——照著抄。」

**畫面**：預告板子內建的接線說明頁（`wiring.html`），接線圖存在板子裡，不需要另外找檔案或印紙本。

把「腳位固定」講成一個優點而不是限制。這句話的實際價值是縮小之後的排查範圍，值得在片頭花一分鐘建立。

### 2. 馬達接到哪一組（1:00–3:00）

**畫面**：樂高 RJ12 轉接板接上驅動板的 OUT1 / OUT2。

> 「先接馬達。樂高線材裡的白線是 MA0、黑線是 MA1，這兩條接到驅動板的 OUT1 和 OUT2。」
>
> 「重點是接在哪一組。有編碼器的樂高馬達，請接在 M3 和 M4。」

| 馬達 | 有編碼器 | 可以下的指令 |
|---|---|---|
| M1 | ✗ | 只能給 PWM |
| M2 | ✗ | 只能給 PWM |
| M3 | ✓ | PWM、角度、轉速 |
| M4 | ✓ | PWM、角度、轉速 |

> 「這門課後面關於角度、閉迴路和參數調整的部分，都只能在 M3 和 M4 上進行。如果編碼馬達接到 M1 或 M2，第二季之後的內容就做不了。」

### 3. 樂高線材的線色需要核對（3:00–4:30）

**畫面**：把 RJ12 的六條線一條一條拉開，逐條特寫顏色。

> 「這裡有一個需要停下來核對的地方，是線的顏色。」
>
> 「一般看到紅線會直覺認為是電源，但在這條線材裡，紅線是接地，綠線才是電源。」
>
> 「請照著下面這張表對，不要照直覺接。」

| Pin | 線色 | 訊號 |
|---|---|---|
| 1 | ⬜ 白 | MA0 → 驅動板 OUT1 |
| 2 | ⬛ 黑 | MA1 → 驅動板 OUT2 |
| 3 | 🟥 紅 | **GND**（不是電源） |
| 4 | 🟩 綠 | **VCC 4.3–5V** |
| 5 | 🟨 黃 | A 相 → M3：GPIO **35** / M4：GPIO **36** |
| 6 | 🟦 藍 | B 相 → M3：GPIO **34** / M4：GPIO **39** |

> 「電源和接地接反的話，編碼器不會運作，也有可能造成元件損壞。這是整支影片最需要花時間核對的一段。」

**畫面**：水晶頭正面特寫，金屬片朝上、卡榫朝下，由左至右是 Pin 1 到 Pin 6。

> 「數針腳的方向是這樣：金屬片朝上、卡榫朝下，由左往右是第一腳到第六腳。」

這段建議放慢，並在畫面上重複標示紅線與綠線的位置。這是全季唯一一個接錯會造成硬體損壞的地方。

### 4. 編碼器不需要外接上拉電阻（4:30–5:00）

**畫面**：黃線與藍線直接接到腳位，鏡頭帶過，畫面上不出現任何電阻。

> 「黃線和藍線直接接到剛才那兩個腳位就好，不需要再加任何電阻。」
>
> 「樂高的編碼器是主動輸出的，高電位和低電位它自己都會驅動，不需要外部的上拉電阻幫忙。」
>
> 「板子內建的接線說明頁也是這樣寫的，你自己去查會得到一致的答案。」

如果換成非樂高的編碼器，這個結論不一定成立，那屬於 BOM § F 的進階內容，這一季不談。

### 5. 舵機與感測器（5:00–7:00）

**畫面**：依序接上舵機、按鈕、超音波，每接一項就在畫面標出對應的 GPIO 編號。

> 「接下來是舵機和感測器。這些也都是固定腳位，照著接就好。」

| 元件 | 腳位 |
|---|---|
| 舵機 S1 | GPIO **5** |
| 舵機 S2 | GPIO **13** |
| 樂高按鈕 | GPIO **4**（另一端接 **GND**） |
| 超音波 Trig | GPIO **2** |
| 超音波 Echo | GPIO **33**（需要分壓，見下） |
| 數位輸入 | GPIO **15** |
| 類比輸入 | GPIO **32** |

**畫面**：畫出超音波 Echo 的分壓接法。

```
Echo ──[ 1kΩ ]──┬── GPIO 33
                │
             [ 2kΩ ]
                │
               GND
```

> 「只有超音波的 Echo 這一條需要多做一件事。」
>
> 「超音波模組要 5 伏特才會運作，它送回來的訊號也是 5 伏特，但 ESP32 的接腳只能承受 3.3 伏特。所以中間要用這兩顆電阻把電壓分掉一部分。」
>
> 「這就是 E01 提到的那組電阻。接法照圖上這樣接就可以。」

### 6. 電源與共地（7:00–8:30）

**畫面**：外接電源接上驅動板，再把電源的 GND 拉到 ESP32 的 GND，兩條線都給特寫。

> 「最後是電源，這一段有兩件事要做。」
>
> 「第一，驅動板一定要接外接電源。ESP32 的 USB 供電推不動馬達，電流請抓 3 安培以上。」
>
> 「第二，外接電源的接地要接到 ESP32 的接地。這條線叫做共地。沒有共同的接地，兩邊的訊號就沒有共同的參考點，編碼器的讀值會不穩定。」

> 「電流不足或沒有共地的時候，現象通常是馬達抽動一下就停、板子突然重新開機、WiFi 斷線，或是編碼器數字亂跳。這些看起來都像是程式的問題，所以之後遇到，請把電源和共地列進檢查範圍。」

這段和 E01 的收尾是同一個訊息，重複是刻意的。電源與共地是後續每一季診斷表裡出現頻率最高的兩個項目。

### 7. 哪些腳位不能用（8:30–9:00）

**畫面**：腳位圖上把已占用的腳位標成紅色。

> 「最後看一下哪些腳位已經被用掉了。」

| GPIO | 用途 |
|---|---|
| 12 14 16 17 19 23 25 27 | 馬達驅動板占用 |
| 5 13 | 舵機 |
| 34 35 36 39 | 編碼器 |

> 「這些腳位不要再外接其他東西。剩下可以自由使用的是 2、4、15、26、32、33。」
>
> 「這門課用不到額外的腳位，這張表是給之後想自己接東西的人參考的。」

## 成功訊號

這一集還沒有可以觀察的電氣訊號，那是 E05 的事。這裡用檢查清單驗收：

- [ ] 有編碼器的馬達接在 **M3 / M4**
- [ ] RJ12 紅線接到 **GND**、綠線接到 **VCC**（核對兩次）
- [ ] 黃線接 35 / 36、藍線接 34 / 39，中間沒有加電阻
- [ ] 超音波 Echo 有經過分壓
- [ ] 外接電源接上驅動板，且電源的 GND 與 ESP32 的 GND 相接
- [ ] 已占用的腳位上沒有外接其他東西

> 「這六項全部確認完再通電。」

## 常見卡點

| 學員的疑問 | 回應 |
|---|---|
| 「線的顏色跟影片不一樣」 | 非原廠線材可能配色不同。請以針腳位置為準，不要以顏色為準 |
| 「接線說明頁提到上拉電阻？」 | 樂高編碼器不需要。那段註記是針對開集極輸出的元件，樂高是主動輸出 |
| 「一定要接滿四顆馬達嗎？」 | 不用。只接 M3 一顆就能走完 S0 到 S3，自檢時把其他項目取消勾選即可 |
| 「GPIO 2 上的 LED 一直亮或暗」 | GPIO 2 同時也是板載 LED，開機瞬間為低電位，屬於正常現象 |
