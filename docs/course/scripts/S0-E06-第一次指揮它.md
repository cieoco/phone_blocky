# S0-E06｜第一次指揮它

**片長目標**：6–7 分鐘
**這集的一句話**：硬體是它的，指令是你的。

---

## 前提

- 自檢九項全綠（E05）

## 器材

- 完整機組
- 手機

---

## 這一集的意義

E05 讓學員看到「它是活的」（*time-to-first-life*）。
**這一集才是「它聽我的」**（*time-to-first-control*）。

兩者不同，而且第二個才是留住學員的關鍵。前一集的動作是機器自己跑的；
這一集手指一動，馬達跟著動——那個因果感是整門課的第一個真正報酬。

---

## 旁白要點

### 1. 開場（0:00–0:40）

> 「上一集所有的動作都是它自己跑的。你只是在旁邊看。」
>
> 「這一集，你的手指動，它就動。」

**畫面**：主選單 → 🕹️ **搖桿**

### 2. 先教緊急停止 ⚠️（0:40–1:20）

**在教怎麼讓它動之前，先教怎麼讓它停。**

**畫面**：畫面最上方的紅色「**緊急停止**」按鈕，按一次示範。

> 「先找到這顆紅色的按鈕。」
>
> 「等一下如果有任何狀況——馬達暴衝、機構卡住、線被捲進去——
> **先按它，不要先去拔電源，也不要用手去抓馬達。**」

> 「這是所有電控的第一課：在你讓一個東西動起來之前，先知道怎麼讓它停。」

### 3. 第一次控制：動力滑桿（1:20–2:40）⭐

**畫面**：M3 的動力滑桿，從 0 慢慢往右拖。

> 「拖右邊，正轉。拖左邊……」

**畫面**：拖到負值，馬達反轉。

> 「反轉。」
>
> 「這條滑桿的範圍是 **-100 到 +100**。」
>
> 「**正負號就是方向**。這件事很重要，因為它是這整套系統的共同語言——
> 你在搖桿上看到的正負號，等一下在積木裡、在別人的參數表裡，意思完全一樣。」

**這是 time-to-first-control 達成的瞬間。** 讓畫面停久一點。

> 「就這樣。你剛剛控制了一顆馬達，沒有寫程式、沒有編譯、沒有燒錄。」

### 4. 換個模式：角度（2:40–4:00）

**畫面**：M3 上方的「動力 / 角度」切換，切到**角度**。

> 「同一顆馬達，換一種指揮方式。」

**畫面**：拖角度滑桿到 90。

> 「這次我不是叫它『用多大力氣轉』，我是叫它『**轉 90 度**』。」
>
> 「然後它就停了。」

**畫面**：特寫下方的即時角度回讀。

> 「而且你看下面這個數字——它一直在回報自己現在幾度。」

> 「注意這個角度滑桿是**相對角度**：拖 90 就是『從現在的位置再轉 90 度』，
> 不是『轉到 90 度那個位置』。這兩個的差別，第二季會講。」

### 5. 用手去推它 —— 埋第二個鉤子（4:00–5:00）⭐

**畫面**：馬達到位停住後，用手去推馬達軸。

> 「它到位了。現在我用手推它——」

**畫面**：手推開，馬達自己夾回原位。

> 「它自己回去了。」

**停頓 2 秒。**

> 「我沒有再下任何指令。」
>
> 「這叫**角度保持**。第三季整整一季都在講這件事——它為什麼知道自己被推開了、
> 它用多大力氣夾回來、力氣太大會怎樣、太小又會怎樣。」
>
> 「現在你只要知道：**它辦得到。**」

> 「想解除的話，按緊急停止，或把模式切回動力。」

### 6. 舵機與搖桿（5:00–6:00）

**畫面**：S1、S2 滑桿。

> 「舵機的滑桿是 **0 到 180 度**，直接指定位置，跟剛剛馬達的角度模式很像——
> 差別是舵機本來就內建這個能力，馬達的是我們自己做出來的。」

搖桿區帶過即可（多馬達協調不是 S0 的重點）。

### 7. 收尾：S0 結束（6:00–6:40）

> 「這一季到這裡。回頭看你做了什麼：」
>
> - 燒錄了一次，之後再也不用
> - 照著固定接線接完了
> - 硬體九項全部驗過
> - **用手機控制了一顆馬達**
>
> 「而且你已經看過兩個還沒解釋的東西：
> **一個會跟著馬達跳動的數字**，和**一顆推不走的馬達**。」
>
> 「下一季開始，我們讓你自己寫程式。
> 然後你會遇到第一個真正的問題——」
>
> 「你叫兩顆馬達都用 30% 的力氣，它們**轉得不一樣快**。」

## 成功訊號

- [ ] 找得到並按過**緊急停止**
- [ ] 拖動力滑桿，馬達**跟著手指**正轉與反轉
- [ ] 切到角度模式，馬達轉指定角度後**停住**
- [ ] 下方**即時角度回讀**有數字
- [ ] 用手推馬達，它**自己回到原位**

| 症狀 | 說明 |

| 滑桿拖了沒反應 | 上方 WebSocket 是否「已連接」→ [§ 0-3](../../卡住了怎麼辦.md) |
| M1/M2 沒有角度模式 | **正常**。M1/M2 沒有編碼器，只能用動力（PWM）→ [§ 5-1](../../卡住了怎麼辦.md) |
| 角度模式沒反應、角度回讀是「—」 | 編碼器沒作用 → [§ 2-1](../../卡住了怎麼辦.md) 查供電與共地 |
| 到位後一直抖 | 正常的角度保持，力道可在設定頁調 → [§ 5-2](../../卡住了怎麼辦.md) |
| 馬達方向跟滑桿相反 | 白黑兩線對調 → [§ 1-3](../../卡住了怎麼辦.md) |
