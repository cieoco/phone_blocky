# S0-E06｜第一次指揮它

**片長目標**：6–7 分鐘
**這集的一句話**：讓觀眾第一次用自己的手指控制馬達，並看到兩個之後才會解釋的現象。

---

## 前提

- 自檢九項全部通過（E05）

## 器材

- 完整機組
- 手機

---

## 這一集的意義（拍攝前必讀）

E05 讓學員看到「它是活的」（*time-to-first-life*），這一集才是「它聽我的」（*time-to-first-control*）。

兩者不同，而且第二個才是留住學員的關鍵。上一集的動作是機器自己跑的；這一集手指一動，馬達跟著動——那個因果感是整門課的第一個實際回報。第 3 段的滑桿鏡頭因此不能剪短。

---

## 旁白要點

### 1. 開場（0:00–0:40）

**畫面**：主選單 → 🕹️ 搖桿。

> 「上一集所有的動作都是板子自己跑的，你只是在旁邊看。」
>
> 「這一集，你的手指動，它就動。」

### 2. 先找到緊急停止（0:40–1:20）

在教怎麼讓它動之前，先教怎麼讓它停。

**畫面**：畫面最上方的紅色「緊急停止」按鈕，示範按一次。

> 「開始之前，先找到這顆紅色的按鈕。」
>
> 「等一下如果發生任何狀況，例如馬達轉速失控、機構卡住、線材被捲進去，請先按這一顆。不要先去拔電源，也不要用手去抓馬達。」
>
> 「這是操作任何會動的機器時的第一個步驟：在讓它動起來之前，先知道怎麼讓它停。」

### 3. 第一次控制：動力滑桿（1:20–2:40）

**畫面**：M3 的動力滑桿，從 0 慢慢往右拖，馬達正轉。

> 「先切到 M3 的動力滑桿，往右拖。」
>
> 「馬達正轉。往左拖——」

**畫面**：拖到負值，馬達反轉。

> 「反轉。」
>
> 「這條滑桿的範圍是負 100 到正 100。」
>
> 「正負號代表的就是方向。這件事請記住，因為它是這整套系統共用的表示方式。你在搖桿上看到的正負號，之後在積木裡、在別人交給你的參數表裡，意思都是一樣的。」

這是 time-to-first-control 達成的瞬間，畫面要停久一點，讓手指的動作和馬達的反應在同一個鏡頭裡完整呈現。

> 「就是這樣。你剛才控制了一顆馬達，沒有寫程式，沒有編譯，也沒有燒錄。」

### 4. 換一種指令：角度（2:40–4:00）

**畫面**：M3 上方的「動力 / 角度」切換，切到角度。

> 「同一顆馬達，換一種指揮方式。」

**畫面**：拖角度滑桿到 90，馬達轉動後停住。

> 「這次我不是叫它用多大力氣轉，而是叫它轉 90 度。」
>
> 「然後它就停了。」

**畫面**：特寫下方的即時角度回讀。

> 「你看下面這個數字，它一直在回報自己現在的角度。這就是 E01 說的那個會回報的零件在做的事。」

> 「另外說明一下，這個角度滑桿是相對角度。拖到 90 的意思是「從現在的位置再轉 90 度」，不是「轉到 90 度那個位置」。這兩者的差別，第二季會處理。」

這裡第一次把 E01 的「編碼器會回報」和螢幕上的實際數字連起來，但仍然不提編碼器這個詞。命名留給第二季。

### 5. 用手推它（4:00–5:00）

**畫面**：馬達到位停住後，用手推馬達軸。

> 「它到位了。現在我用手推它——」

**畫面**：手推開，馬達自己回到原位。

> 「它自己回去了。」

**停頓兩秒。**

> 「我沒有再下任何指令。」
>
> 「這個功能叫做角度保持。第三季整整一季都在講它——它怎麼知道自己被推開了、它用多大力氣回去、力氣太大會怎麼樣、太小又會怎麼樣。」
>
> 「現在你只要先知道：它做得到。」

> 「想解除這個狀態的話，按緊急停止，或是把模式切回動力。」

這是本季埋下的第二個鉤子，和 E05 的跳動數字對應。同樣只展示、不解釋。

### 6. 舵機與搖桿（5:00–6:00）

**畫面**：S1、S2 的滑桿，拖動時舵機轉到對應角度。

> 「舵機的滑桿是 0 到 180 度，可以直接指定位置。」
>
> 「這和剛才馬達的角度模式看起來很像，差別在於舵機本來就內建這個能力，而馬達的角度控制是我們自己做出來的。這就是 E01 提到的那件事。」

**畫面**：搖桿區帶過即可。

> 「下面的搖桿區可以同時控制多顆馬達，這一季先不用，之後會用到。」

### 7. 收尾：S0 結束（6:00–6:40）

**畫面**：整組機組全景。

> 「這一季到這裡結束。回頭看你完成了什麼：」
>
> - 燒錄了一次，之後不用再燒
> - 照著固定的位置把線接完
> - 硬體九項全部驗證過
> - 用手機控制了一顆馬達

> 「另外，你已經看過兩個還沒有解釋的東西：一個會跟著馬達跳動的數字，和一顆推不走的馬達。」
>
> 「下一季開始，你會自己寫程式。然後你會遇到第一個真正屬於電控的問題——」
>
> 「你叫兩顆馬達都用 30% 的力氣，它們轉得不一樣快。」

## 成功訊號

- [ ] 找得到並按過緊急停止
- [ ] 拖動力滑桿，馬達跟著手指正轉與反轉
- [ ] 切到角度模式，馬達轉到指定角度後停住
- [ ] 下方的即時角度回讀有數字
- [ ] 用手推馬達，它自己回到原位

## 常見卡點

| 症狀 | 說明 |
|---|---|
| 滑桿拖了沒有反應 | 檢查上方的 WebSocket 是否顯示「已連接」→ [§ 0-3](../../卡住了怎麼辦.md) |
| M1 / M2 沒有角度模式 | 正常。M1 / M2 沒有編碼器，只能用動力（PWM）→ [§ 5-1](../../卡住了怎麼辦.md) |
| 角度模式沒反應、角度回讀顯示「—」 | 編碼器沒有作用 → [§ 2-1](../../卡住了怎麼辦.md) 檢查供電與共地 |
| 到位之後一直輕微抖動 | 這是角度保持的正常現象，力道可以在設定頁調整 → [§ 5-2](../../卡住了怎麼辦.md) |
| 馬達轉向和滑桿相反 | 白黑兩線對調 → [§ 1-3](../../卡住了怎麼辦.md) |
