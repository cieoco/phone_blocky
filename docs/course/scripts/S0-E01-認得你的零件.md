# S0-E01｜認得你的零件

**片長目標**：6–7 分鐘
**這集的一句話**：讓觀眾看懂每個零件負責什麼，以及它們之間的指揮關係。

---

## 前提

料件已到貨（E00）。

## 器材

- 全部料件攤平在桌上，未組裝
- 一顆兩線的一般直流馬達（用來對照編碼馬達的六芯線）

---

## 旁白要點

### 1. 先建立一條指揮鏈（0:00–1:20）

**畫面**：零件由左到右排成一條線，鏡頭從左緩緩橫移到右；講到編碼器時，畫面加上一條由右往左的回頭箭頭。

```
你的手機  →  ESP32 板  →  馬達驅動板  →  馬達
                ↑                          │
                └──── 編碼器 ←─────────────┘
```

> 「桌上這些零件看起來很分散，但它們其實排成一條線。」
>
> 「手機發出指令，ESP32 收到後決定要怎麼做，驅動板把訊號放大成馬達推得動的電流，馬達轉動。這是一條由左往右的指揮鏈。」
>
> 「只有一個零件是反過來的——編碼器。它裝在馬達這一端，把馬達實際轉了多少回報給 ESP32。」
>
> 「前面幾站都是『我叫你做』，只有這一站是『我做完了，結果是這樣』。這個方向的差別，是後面整門課的基礎。」

這一段先給觀眾一張地圖。後面每介紹一個零件，都要能指回這條鏈上的位置，避免變成規格朗讀。

### 2. 三個主角：腦、力氣、出力（1:20–3:00）

**畫面**：依序把 ESP32、驅動板、馬達拿到鏡頭前，特寫。

> 「先看三個主角。」

**WeMos D1 R32（ESP32）**

> 「這片是整台的腦。它同時做三件事：開一個 WiFi 熱點讓你的手機連進來、當網頁伺服器把操作畫面送到手機上、以及跑控制迴圈去指揮馬達。」
>
> 「你手機上看到的每一個畫面，都是它送出來的。」

**馬達驅動板**

> 「ESP32 送得出訊號，但它的接腳只能輸出很小的電流，推不動馬達。中間需要這一片驅動板。」
>
> 「它的工作是把 ESP32 的小訊號，轉換成馬達推得動的大電流。它會直接插在 ESP32 上面，我們在下一集接線的時候會處理。」

**馬達**

> 「馬達負責出力。它接收的指令是『用多大的力氣往哪個方向轉』，只要不叫停，它就會一直轉下去。」
>
> 「請先記住這一點：馬達本身不知道自己轉到哪裡了。」

最後一句是為第 4 段的「馬達與舵機的差別」鋪路，這裡先埋一句，不展開。

### 3. 其餘四件：回報、角度、電力、保護（3:00–4:40）

**畫面**：每件拿起來特寫。介紹編碼器時，把編碼馬達的六芯線與一般馬達的兩芯線並排比較。

**編碼器**

> 「編碼器藏在樂高馬達的殼裡面，從外觀看不到。」
>
> 「分辨方式是看線：有編碼器的馬達會有六條芯線，沒有編碼器的一般馬達只有兩條。你手上如果只有兩條線，那就是沒有編碼器的。」
>
> 「它的工作是數馬達轉了多少，然後把這個數字回報給 ESP32——也就是剛才那條鏈上，唯一一個往回走的箭頭。」

**舵機**

> 「舵機和馬達不一樣。你可以直接告訴它『去 90 度』，它自己會轉到那裡停住。」
>
> 「它做得到，是因為它的殼裡面本來就有一組偵測角度和自動修正的機制。這件事等一下會再提到。」

**外接電源**

> 「馬達要用的電流，ESP32 的 USB 供不起。所以馬達的電必須從這個外接電源另外進來。」
>
> 「這不是選配。少了它，馬達不會轉，或是一轉板子就重新開機。」



**拍攝參考表**（不用唸出來，供剪輯時做字幕與標註）

| 零件 | 負責什麼 | 沒做好時的現象 |
|---|---|---|
| **WeMos D1 R32（ESP32）** | 開熱點、送網頁、跑控制迴圈 | 沒燒錄 → 手機找不到熱點 |
| **馬達驅動板** | 把小訊號放大成大電流 | 沒外接電源 → 馬達完全不動 |
| **馬達** | 出力 | — |
| **編碼器**（在樂高馬達內） | 回報實際轉了多少 | 沒供電或沒共地 → 馬達會轉但數字不動 |
| **舵機** | 直接指定角度，內建閉迴路 | 供電不足 → 抖動、嗡嗡聲 |
| **外接電源** | 供應馬達電流 | 電流不足 → 一動就重開機 |
| **1kΩ + 2kΩ 電阻** | 超音波 Echo 分壓 | 沒接 → 接腳長期超壓 |

### 4. 兩個要先建立的觀念（4:40–6:10）

**(a) 馬達和舵機，能接受的指令不一樣**

**畫面**：左邊馬達持續轉動不停，右邊舵機轉到 90 度後停住，兩邊同框對照。

> 「同樣是會轉的東西，但你能對它們下的指令不一樣。」
>
> 「馬達只能接受『用多大力氣、往哪個方向轉』，它不會自己停在某個角度。舵機可以直接接受『去 90 度』，因為它內部有偵測角度、自動修正的機制。」
>
> 「這門課後半段要做的事，就是替馬達補上舵機本來就有的那套機制——用編碼器量角度，用程式做修正。」

這是全季最重要的一個對照。舵機在這裡不是課程主角，而是「馬達最後要達到的樣子」的現成範例。

**(b) 四顆馬達的能力不一樣**

**畫面**：驅動板上的 M1–M4 標示逐一點亮，M3、M4 額外加上編碼器圖示。

> 「驅動板上有四個馬達接口，但它們的能力不同。」
>
> 「M1 和 M2 沒有接編碼器，M3 和 M4 有。」
>
> 「所以對 M1、M2，你只能下『用多大力氣轉』；對 M3、M4，才能下『轉到幾度』。」
>
> 「這樣安排是為了讓你在同一塊板子上做對照——同樣的指令，有回報和沒有回報的差別在哪裡。這個對照會在第二季正式用到。」

### 5. 收尾：先把電源放在心上（6:10–6:50）

**畫面**：把外接電源單獨放在鏡頭前。

> 「最後回到電源。」
>
> 「電流不足的時候，系統不會直接告訴你電不夠。它的表現是馬達抽動一下就停、板子突然重新開機、WiFi 斷線，或是編碼器數字亂跳。」
>
> 「這些現象看起來都很像程式或接線出了問題。所以之後只要遇到這幾種狀況，請先把電源列進檢查範圍。」

不要把電源講成陷阱或恐嚇。這裡的目的是給觀眾一條之後用得到的診斷線索。

## 成功訊號

這集沒有動手項目。看完後，學員應該能對著自己桌上的零件說出：

- [ ] 哪一片是腦、哪一片負責放大電流
- [ ] 哪個零件是唯一會回報的，以及怎麼從線的數量分辨
- [ ] 哪兩顆馬達有編碼器、哪兩顆沒有
- [ ] 馬達和舵機能接受的指令差在哪裡

---

## 常見卡點

| 學員的疑問 | 回應 |
|---|---|
| 「編碼器要不要另外接電阻？」 | 樂高馬達不用。接法見 E03 |
| 「樂高馬達看不到編碼器在哪」 | 它在馬達殼內部，外觀看不到。從線材是六芯（而不是兩芯）就可以確認 |
| 「我買的馬達只有兩條線」 | 那是沒有編碼器的一般直流馬達，可以接在 M1／M2 使用 |
| 「一定要兩顆電阻嗎？可以只用一顆？」 | 分壓需要兩顆搭配。阻值與接法見 BOM 與 E03 |
