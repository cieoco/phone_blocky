# S0-E01｜認得你的零件

**片長目標**：6–7 分鐘
**這集的一句話**：每個零件負責什麼，以及它們之間誰在指揮誰。

---

## 前提

料件已到貨。

## 器材

全部料件攤平在桌上，未組裝。

---

## 旁白要點

### 1. 用「誰在指揮誰」串起來，不要逐項唸規格（0:00–1:30）

**畫面**：從左到右擺成一條指揮鏈。

```
你的手機  →  ESP32 板  →  馬達驅動板  →  馬達
                ↑                          │
                └──── 編碼器 ←─────────────┘
```

> 「這條鏈只有一個地方是反過來的——編碼器。
> 其他都是『我叫你做』，只有編碼器是『我做完了，回報給你』。
> 記住這個方向，後面所有東西都是這條鏈的延伸。」

### 2. 逐件介紹（1:30–5:00）

每件講三句：**它是誰、它負責什麼、它出問題時你會看到什麼。**

| 零件 | 負責什麼 | 出問題時 |
|---|---|---|
| **WeMos D1 R32（ESP32）** | 整台的腦。同時開 WiFi 熱點、當網頁伺服器、跑控制迴圈 | 沒電/沒燒錄 → 手機找不到熱點 |
| **馬達驅動板** | 腦的力氣太小，推不動馬達。這片負責放大 | 沒外接電源 → 馬達完全不動 |
| **馬達** | 出力 | — |
| **編碼器**（藏在樂高馬達裡） | **唯一會回報的零件**。它數馬達轉了多少 | 沒供電或沒共地 → 馬達會轉但數字不動 |
| **舵機** | 直接指定角度，內建自己的閉迴路 | 供電不足 → 抖動、嗡嗡叫 |
| **外接電源** | 餵馬達。**ESP32 的 USB 餵不動** | 電流不夠 → 一動就重開機 |
| **1kΩ + 2kΩ 電阻** | 超音波 Echo 的分壓 | 沒接 → 短期會動，長期傷板 |

### 3. 特別強調兩件事（5:00–6:30）

**(a) 馬達與舵機不是同一種東西**

> 「馬達你只能叫它『用多大力氣轉』，它會一直轉下去。
> 舵機你可以直接叫它『去 90 度』，它自己會停在那裡。」
>
> 「這門課後半段最核心的一件事，就是——**怎麼讓馬達也能做到舵機那件事**。」

**(b) 四顆馬達不是平等的**

> 「M1、M2 沒有編碼器，M3、M4 有。」
> 「所以 M1、M2 你只能叫它『轉多用力』，M3、M4 才能叫它『轉到幾度』。」
> 「這不是設計缺陷，是刻意留著的——讓你親眼看到有回授跟沒回授差在哪。」

### 4. 收尾（6:30–7:00）

**畫面**：把外接電源放在鏡頭前。

> 「最後提醒一個最不起眼、但最會害人的東西——電源。」
>
> 「它出問題的時候，不會告訴你『我電流不夠』。
> 它會讓馬達抽一下就停、讓板子突然重開機、讓 WiFi 斷線、讓編碼器數字亂跳。」
>
> 「然後你會去查程式，查一整個下午。」

## 成功訊號

學員能對著自己桌上的零件說出：

- [ ] 哪一片是腦、哪一片是放大力氣的
- [ ] 哪個零件是唯一會「回報」的
- [ ] 哪兩顆馬達有編碼器、哪兩顆沒有

---

## 常見卡點

| 症狀 | 說明 |
|---|---|
| 「編碼器要不要另外接電阻？」 | 樂高馬達**不用**。詳見 E03 |
| 「樂高馬達看不到編碼器在哪」 | 它在馬達殼內部，看不到。從線材有 6 芯（而不是 2 芯）就知道有 |
| 「我買的馬達只有兩條線」 | 那就是沒有編碼器的一般直流馬達，只能當 M1/M2 用 |
