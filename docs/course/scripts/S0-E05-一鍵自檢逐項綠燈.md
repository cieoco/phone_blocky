# S0-E05｜一鍵自檢：逐項綠燈

**片長目標**：9–10 分鐘（本季最長）
**這集的一句話**：在寫任何程式之前，先讓觀眾確認硬體是對的。

---

## 前提

- 手機連得上，主選單看得到（E04）

## 器材

- 完整機組，全部接好並通電

---

## 這一集的教學設計（拍攝前必讀）

這一集有兩層目的，第二層在片中不能講破：

| 層 | 目的 |
|---|---|
| 表層 | 驗收硬體，找出接錯的地方 |
| 裡層 | 讓學員第一次親眼看到「馬達轉動時，有一個數字跟著變」 |

那個現象就是回授，但這一集不命名、不解釋，只請學員留意。

到第二季講編碼器時，開場會是「還記得自檢時那個跟著跳的數字嗎」。那時候的作用不是引入新概念，而是替他早就看過的現象取名字。這是最有效的導入順序，如果這一集講破了，那個效果就沒有了。

---

## 旁白要點

### 1. 為什麼要先自檢（0:00–1:30）

**畫面**：主選單停在螢幕上，手指停在「積木程式」上方，然後移開，改點「硬體功能檢測」。

> 「你現在應該很想直接開始寫程式。這裡先花十分鐘做一件別的事。」
>
> 「原因是這樣：如果現在直接去拖積木，等一下馬達不動的時候，可能的原因有三個——程式寫錯了、線接錯了，或是硬體本身有問題。」
>
> 「三個原因同時存在，很難判斷是哪一個。」
>
> 「所以我們先把「線」和「硬體」這兩個確認掉。之後只要有東西不動，剩下的可能就只有程式一個，你就查得完。」

這是二分法的第一課，而且是用做的，不是用講的。這一段不要跳過，它決定學員之後遇到問題時的處理方式。

### 2. 進入自檢頁（1:30–2:30）

**畫面**：主選單 → 🔧 硬體功能檢測，九個項目的卡片列表。

| # | 項目 |
|---|---|
| 1–4 | M1、M2、M3（含編碼器）、M4（含編碼器） |
| 5 | 舵機 S1 / S2 |
| 6 | 樂高按鈕 |
| 7 | 超音波 |
| 8 | 數位讀值 |
| 9 | 類比讀值 |

> 「這裡有九個項目。沒有接的東西就把勾選取消掉，只接了一顆馬達也沒有關係，勾那一項就好。」

**畫面**：特寫上方的連線狀態。

> 「開始之前先確認上方顯示的是「WebSocket 已連接」。如果是紅色的，回到上一集檢查行動網路有沒有關掉。」

### 3. 這個頁面不會幫你判斷（2:30–3:30）

這一段決定學員把這個工具當成玩具還是助教，請完整講完。

> 「有一件事要先說明：這個頁面不會自己判斷通過或失敗。」
>
> 「它會幫你做動作，然後問你「這樣正常嗎」。做判斷的是你。」
>
> 「所以請你在每一項跑的時候，真的抬起頭看馬達，不要習慣性地按「是」。」
>
> 「這一步按錯的話，錯誤會一直留在系統裡，而且要到後面幾季才會浮現。到時候要花的時間，比現在多看兩眼多得多。」

### 4. 跑 M1（3:30–4:30）

**畫面**：按下 M1 的測試按鈕，馬達開始動作。

自動序列是：正轉由慢加速到最快 → 停止 → 反轉由慢加速到最快 → 停止。

> 「按下去之後，馬達會自己跑一段程序。你要看的有四件事：正轉、加速、停止、反轉。」
>
> 「特別注意最後的反轉。如果兩次都往同一個方向轉，那就是有問題，通常是接線的問題。」

**畫面**：跑完後出現確認框，四個勾選項目。

> 「跑完會跳出確認框，四個項目對照著剛才看到的回答就可以。」

### 5. 跑 M3——本集核心（4:30–6:30）

**畫面**：M3 的區塊，特寫「🔄 編碼器即時計數」那個數字，畫面停留三秒讓觀眾看清楚它現在是 0。

> 「M3 和 M1 有一個地方不一樣。」
>
> 「你看這裡，這個數字。」
>
> 「我現在按下去。請你同時看著馬達，也看著這個數字。」

**畫面**：馬達開始轉動，數字快速跳動。這裡不要旁白，讓畫面說話五秒。

> 「馬達在轉的時候，這個數字就在跳。」
>
> 「馬達停下來，它就停住。」
>
> 「馬達反過來轉，它就往回減。」

**停頓兩秒。**

> 「我現在先不解釋這是什麼。」
>
> 「你只要記住一件事：這台機器在動的時候，有一個數字知道它動了多少。」
>
> 「第二季我們會回來看它。」

**畫面**：跑完後的確認框，特寫計數範圍與總變化量。

> 「確認框裡有兩個數字，計數範圍和總變化量。這兩個只要不是零，就代表這一項是正常的。」

這一段是全季最重要的畫面。務必用雙畫面同框拍攝，讓馬達和數字在同一個鏡頭裡，不要切鏡頭。切了就看不出因果關係。

### 6. 舵機、按鈕、超音波、數位、類比（6:30–8:30）

**畫面**：節奏加快，每一項 20 到 30 秒。

> 「剩下五項比較快，一項一項跑過去。」

| 項目 | 觀察重點 |
|---|---|
| 舵機 | S1 掃到 0、90、180 再回中，然後換 S2。兩顆都要會動 |
| 按鈕 | 沒按的時候是 1、按下去是 0。數值反過來是正常的 |
| 超音波 | 手掌在正前方前後移動，數字要跟著變。距離小於 2 公分量不到 |
| 數位 | 觸發時 HIGH 和 LOW 要會切換 |
| 類比 | 數值在 0 到 4095 之間，接近感測器時要連續變化 |

> 「按鈕那一項要特別說明一下：沒按是 1、按下去是 0，這個方向是反的，但它是正常的。這塊板子用的是內部上拉，所以按下去等於接到地。」
>
> 「這五項現在測過之後，第四季用它們做判斷的時候，就不需要再接一次線。」

### 7. 全部通過之後（8:30–9:30）

**畫面**：九項全部顯示綠色。

> 「到這裡你知道了一件很有用的事：你的硬體是對的。」
>
> 「這句話的實際意義是——從現在開始，只要有東西不動，你可以先跳過硬體，直接去看程式。」
>
> 「剛才那三個可能的原因，現在只剩下一個。」

> 「如果有哪一項是紅色的，先不要往下走。打開「卡住了怎麼辦」，它就是照這九項編排的，哪一項紅了就翻到對應的那一段。」

---

## 成功訊號

- [ ] 有接的項目全部通過（沒接的已取消勾選）
- [ ] M3 / M4 的編碼器計數會跟著馬達跳動，總變化量不是 0
- [ ] 學員記住了「有一個數字知道它動了多少」（不需要知道它叫什麼）
