# S0-E04｜手機連上它

**片長目標**：4–5 分鐘
**這集的一句話**：讓觀眾用手機連上板子並打開操作畫面，確認韌體與網頁都已就緒。

---

## 前提

- 線已接好、電源已接上（E03）

## 器材

- 通電的完整機組
- 一支手機（Android 與 iPhone 各示範一次最好）

---

## 旁白要點

### 1. 從這裡開始換工具（0:00–0:45）

**畫面**：把電腦推到旁邊，或直接闔上筆電，鏡頭停在手機上。

> 「電腦可以收起來了。從現在開始到這門課結束，你都不會再用到它。」
>
> 「接下來所有的操作、寫程式和調參數，都在這支手機上完成。」

E02 已經說過「只需要燒錄一次」，這裡是那句話的兌現。這一段不用長，但要讓觀眾實際看到電腦離開畫面。

### 2. 連上板子的熱點（0:45–1:30）

**畫面**：手機的 WiFi 清單，`ESP32-` 開頭的項目出現在列表中。

> 「打開手機的 WiFi 清單，你會看到一個 `ESP32-` 開頭的熱點，後面四碼是這塊板子的編號。」
>
> 「密碼是 `12345678`。」
>
> 「這個熱點是板子自己開出來的。它不會連到網際網路，它的用途只是讓你的手機連得到這塊板子。」

### 3. 連線之後的提示要選「保持」（1:30–3:00）

這一段是全集重點，節奏要放慢。

**畫面**：手機跳出「此網路沒有網際網路連線」的提示。

> 「連上之後，手機通常會跳出一個提示：『此網路沒有網際網路連線，是否要保持連線？』」
>
> 「這裡要選『保持』或『仍要使用』。」
>
> 「如果選了否，或者手機同時開著行動網路，系統會判斷這個 WiFi 不能上網，然後把流量切回行動網路。」
>
> 「這種狀況下，網頁有可能因為快取而打得開，但操作沒有反應。」

**畫面**：實際示範關閉行動數據的操作。

> 「最穩定的做法是先把行動網路關掉，再連這個熱點。之後每次要操作板子，都建議這樣做。」

這個現象在後面幾集的診斷表會反覆出現。在這裡示範一次關閉行動網路的實際操作，之後就可以直接引用。

### 4. 打開操作畫面（3:00–4:00）

**畫面**：瀏覽器網址列輸入 `192.168.4.1`。

> 「打開瀏覽器，在網址列輸入 `192.168.4.1`。」
>
> 「注意是 `http`，不是 `https`。網址要輸入完整，只打數字的話手機可能會拿去搜尋。」

**畫面**：主選單出現，鏡頭逐項帶過。

| 頁面 | 用途 |
|---|---|
| 🧩 積木程式 | 用拖積木的方式寫程式 |
| 🕹️ 搖桿 | 即時控制馬達與舵機 |
| 🔧 硬體功能檢測 | 逐項驗收硬體 |
| 🔌 接線說明 | 接線圖 |
| ⚙️ 設定 | WiFi、PID、角度保持 |

> 「這是主選單，每個項目後面幾集都會用到，現在先知道有這些頁面就好。」
>
> 「其中「接線說明」這一頁請留意一下——接線圖是內建在板子裡面的。之後要接線或核對腳位，不用去翻筆記或找檔案，打開這一頁就有。」

### 5. 收尾（4:00–4:30）

**畫面**：主選單停留在螢幕上。

> 「這個畫面出現，代表三件事都完成了：韌體燒進去了、網頁也燒進去了，而且你的手機連得到這塊板子。」
>
> 「硬體的準備到這裡結束。」

---

## 成功訊號

- [ ] 手機的 WiFi 清單看得到 `ESP32-XXXX`
- [ ] 用密碼 `12345678` 連得上
- [ ] 瀏覽器打開 `192.168.4.1` 看得到主選單（不是空白頁，也不是 404）

---

## 常見卡點

| 症狀 | 首先檢查 |
|---|---|
| 找不到熱點 | 板子有沒有電？序列監視器有沒有輸出？必要時回到 E02 重燒 |
| 連得上但網頁是空白或 404 | `littlefs.bin` 沒有燒錄。網頁和韌體是分開的兩份檔案，回 E02 把四個檔案全部燒一次 |
| 網址打不開 | 完整輸入 `http://192.168.4.1`，不要用 `https` |
| 網頁開了但按鈕沒有反應 | 行動網路沒有關閉，見第 3 段 |
| 連線一直被中斷 | 同時最多支援 4 台裝置連線；也可能是電流不足導致板子重新開機 |

完整清單見 [卡住了怎麼辦 § 0](../../卡住了怎麼辦.md)。
