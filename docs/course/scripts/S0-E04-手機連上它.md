# S0-E04｜手機連上它

**片長目標**：4–5 分鐘
**這集的一句話**：從現在起，你的開發環境是一支手機。

---

## 前提

- 線已接好、電源已接（E03）

## 器材

- 通電的完整機組
- 一支手機（Android 與 iPhone 各示範一次最好）

---

## 旁白要點

### 1. 這一刻的意義（0:00–0:45）

**畫面**：把電腦推到旁邊，或直接闔上筆電。

> 「電腦收起來。從現在開始到這門課結束，你都不會再用到它。」
>
> 「你的開發環境是這支手機。」

### 2. 連熱點（0:45–1:30）

**畫面**：手機 WiFi 清單。

- 熱點名稱：`ESP32-` + MAC 末四碼（例如 `ESP32-DB50`）
- 密碼：`12345678`

> 「這個熱點是板子自己開的。它不上網，它只是讓你連得到它。」

### 3. ⚠️ 最容易卡的一步（1:30–3:00）

**這一段是全集重點，要放慢。**

> 「連上之後，你的手機大概會跳出一句話：
> **『此網路沒有網際網路連線，是否要保持連線？』**」
>
> 「一定要選『**保持**』或『**仍要使用**』。」

> 「如果你按了『否』，或者你的手機開著行動網路——
> Android 會很聰明地判斷『這個 WiFi 不能上網』，然後**自動把流量切回 4G/5G**。」
>
> 「結果就是：網頁打得開（因為快取），但按什麼都沒反應。
> 你會以為板子壞了。」

**建議做法**：

> 「最保險的做法是——**先把行動網路關掉**，再連這個熱點。」

**畫面**：實際示範關閉行動數據。

### 4. 開網頁（3:00–4:00）

**畫面**：瀏覽器輸入 `192.168.4.1`。

> 「注意是 `http`，不是 `https`。而且要打完整，不然手機會拿去搜尋。」

主選單出現，逐個介紹（每個一句話就好）：

| 頁面 | 一句話 |
|---|---|
| 🧩 積木程式 | 拖積木寫程式 |
| 🕹️ 搖桿 | 即時控制 |
| 🔧 **硬體功能檢測** | **下一集的主角** |
| 🔌 接線說明 | 接線圖就在板子裡 |
| ⚙️ 設定 | WiFi、PID、角度保持 |

> 「注意『接線說明』這一頁——**接線圖是內建在板子裡的**。
> 你以後接線不用去翻筆記、不用找檔案，開這一頁就有。」

### 5. 收尾（4:00–4:30）

> 「這個畫面出現，代表三件事都對了：
> 韌體燒進去了、網頁也燒進去了、你的手機連得到它。」

---

## 成功訊號

- [ ] 手機 WiFi 清單看得到 `ESP32-XXXX`
- [ ] 連得上（密碼 `12345678`）
- [ ] 瀏覽器開 `192.168.4.1` **看得到主選單**（不是空白、不是 404）

---

## 常見卡點

| 症狀 | 首查 |
|---|---|
| 找不到熱點 | 板子有電嗎？序列監視器有輸出嗎？→ 回 E02 重燒 |
| 連得上但網頁**空白 / 404** | **`littlefs.bin` 沒燒**。網頁和韌體是分開的兩份，回 E02 把四個檔全燒一次 |
| 網址打不開 | 完整輸入 `http://192.168.4.1`，別用 `https` |
| 網頁開了但按鈕沒反應 | **行動網路沒關**，見上面第 3 段 |
| 一直被踢掉 | 同時最多 4 台裝置連線；或電源電流不足導致板子重開機 |

完整清單見 [卡住了怎麼辦 § 0](../../卡住了怎麼辦.md)。
