# S0-E02｜燒錄：一輩子只做一次

**片長目標**：7–8 分鐘
**這集的一句話**：把韌體寫進板子，之後你再也不用碰電腦。

---

## 前提

- 零件已認完（E01）
- **需要一台 Windows 電腦**（這是全課程唯一一次）
- 一條**能傳資料**的 USB 線

## 器材

- WeMos D1 R32 + AFMotor Shield（插好，先不接馬達與電源）
- USB 線
- 電腦

---

## 旁白要點

### 1. 先講清楚為什麼只有這次要用電腦（0:00–1:00）

> 「這一集是整門課唯一一次你需要打開電腦。做完之後，你所有的程式都在手機上拖，
> 不用編譯、不用重燒、不用再插線。」

> 「原因是這塊板子裡跑的不是『你的程式』，而是一個**能聽懂指令的直譯器**。
> 直譯器燒一次就固定了，之後我們換的是指令，不是韌體。」

不要展開講架構（那是 S5 選修），一句話帶過就好。

### 2. 用 Configurator，不要用 PlatformIO（1:00–2:00）

**畫面**：雙擊 `PhoneBlockyMotorTuner.exe`。

> 「不用裝 Python，不用裝 PlatformIO，不用去找 Espressif 的燒錄工具。
> 四個韌體檔已經包在這個 EXE 裡面了，雙擊就開。」

> 「這種東西業界叫 Configurator——刷韌體、調參數、即時控制全在一個視窗。
> 玩無人機的人熟悉的 Betaflight Configurator 就是同一類。」

### 3. 接線與 COM 埠（2:00–3:30）

**畫面**：USB 插上板子 → 裝置管理員出現 COM 埠。

> ⚠️ **這裡最常卡的是 USB 線。** 很多充電線只有電源線、沒有資料線，
> 插上去電腦完全沒反應。**換一條線**是第一個要試的事，不是重裝驅動。

工具開啟後切到最右邊的「**燒錄**」分頁。

### 4. 燒錄前務必先「斷線」（3:30–4:00）⚠️

> 「這一步最容易漏。如果你剛剛在最上面的連線列連過 USB，一定要先按『斷線』。」
> 「燒錄程式需要獨占那個 COM 埠，你占著它就燒不進去。」

**畫面**：明確指出「斷線」按鈕，按下去。

> 補充：燒錄分頁**有自己的 COM 埠選單**，跟最上方連線列是兩處，以燒錄分頁選的為準。

### 5. 確認四個檔案（4:00–5:30）

**畫面**：四列表格，都已預設勾選、Offset 已填好。

| bin 檔 | Offset | 內容 |
|---|---|---|
| `bootloader.bin` | `0x1000` | 開機載入器 |
| `partitions.bin` | `0x8000` | 分區表 |
| `firmware.bin` | `0x10000` | 主韌體 |
| `littlefs.bin` | `0x1B9000` | **網頁**（手機上看到的所有畫面） |

> 「**首次燒錄四個全燒。**」
>
> 「特別注意最後一個 `littlefs.bin`——那是你手機上會看到的所有網頁。
> 韌體和網頁是**分開的兩份東西**。只燒韌體不燒網頁，熱點會出來，但網頁打不開。
> 這是很多人第一次卡住的地方。」

Offset 已經預設帶好，**不要改**。

### 6. 開始燒錄（5:30–6:30）

**畫面**：按「開始燒錄」，log 區跑起來。

> Baud 預設 `921600` 最快。如果中途常斷線或報錯，改成 `460800` 或 `115200`，
> 慢一點但穩。

看到 log 顯示「**燒錄完成，請重新啟動 ESP32**」就成功了。

### 7. 重啟（6:30–7:00）

按板上的 RST，或重新插拔 USB。

---

## 成功訊號

**這集的驗收不是「燒錄完成」四個字，而是——**

> 拿出手機打開 WiFi 清單，**看到一個 `ESP32-` 開頭的熱點**（例如 `ESP32-DB50`，
> 後面四碼是你這塊板子的 MAC 末四碼）。

看到熱點 = 韌體活了。
（網頁有沒有燒進去，要到 E05 開網頁才知道——所以那時如果空白，回來重燒 `littlefs.bin`。）

## 常見卡點

| 症狀 | 首查 |
|---|---|
| 電腦看不到 COM 埠 | **換一條 USB 線**（充電線沒有資料線）→ 再查 CH340/CP2102 驅動 |
| 按「開始燒錄」沒反應 / 埠被占用 | 沒按「斷線」；或序列監視器、其他程式占著該埠 |
| 燒到一半 `A fatal error occurred` | Baud 調低到 `460800` 或 `115200`；換 USB 埠（避開 hub） |
| 燒完了但沒有熱點 | 四個檔有沒有全燒？Offset 有沒有被改到？勾「燒錄前清除 flash」重燒一次 |
| 之前燒壞、開不了機 | 勾「**燒錄前清除 flash**」整顆清空再寫 |

完整 FAQ 見 [安裝教程 § 常見問題](../../安裝教程.md)。
