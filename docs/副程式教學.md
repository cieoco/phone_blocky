# 副程式教學：用兩輪小車學「把動作包起來」

給老師和學生一起看。對應的範例在積木頁 📚 的 **G 小車副程式** 系列（51～56）。
累積的暖身另有 [24-procedure](範例程式.md)（舵機抖一下），可以先帶一遍。

## 小車的接法（本系列的共同假設）

| 輪子 | 馬達 | 說明 |
|------|------|------|
| 左輪 | M1 | 沒有編碼器，只能用「馬達動力」 |
| 右輪 | M2 | 同上 |

兩輪都給正的動力 = 前進。**如果你的車某顆輪子裝反了，車會原地打轉**，
這正好是第 52 步要示範的：只改副程式裡的一個地方就好。

## 為什麼要副程式？先看 51 的痛點

打開 `51-car-no-proc`：只是「前進、左轉、前進、停」四個動作，卻用了十幾塊積木，
而且「前進」要把兩塊馬達積木寫兩次。想想看：

- 要再多走一個彎，是不是又要複製一大串？
- 某一顆輪子裝反，要改幾個地方？
- 別人看得懂這段在做什麼嗎？

**副程式就是給一串積木取一個名字**，要用的時候喊名字就好。

## 名詞

| 名詞 | 意思 |
|------|------|
| 定義 | 寫出「前進」這個名字底下有哪些積木。只寫一次，放在 setup／loop 外面 |
| 呼叫 | 在主程式裡用「前進」積木，意思是「把那一串積木現在執行一遍」 |
| 參數 | 呼叫時才填的空格。例如 `前進(毫秒)`，呼叫 `前進(1000)` 就是毫秒 = 1000 |

**忘了呼叫，副程式就不會動**。只有定義、沒有呼叫，等於寫了食譜卻沒下廚。

## 階梯：每一步多學一件事

| 範例 | 這一步多學了什麼 |
|------|------------------|
| `51-car-no-proc` | 不用副程式：看見重複、難讀的痛點 |
| `52-car-actions` | 副程式（沒有參數）：前進／左轉／右轉／停車，主程式像一句話；輪子裝反只改一處 |
| `53-car-time-param` | 一個參數：`前進(毫秒)`，把「走多久」變成呼叫時才填的空格 |
| `54-car-drive-lr` | 兩個參數：`開車(左輪, 右輪)`，轉向 = 左右輪速度差 |
| `55-car-square` | 副程式呼叫副程式：`走正方形` 用 `前進`、`右轉` 組成 |
| `56-car-avoid` | 副程式加感測：超音波看到障礙就呼叫 `閃避` |

### 52：動作副程式

主程式變成：前進、等 1 秒、左轉、等 0.4 秒、前進、等 1 秒、停車。
練習：把右輪的方向改成 BACKWARD，看車子怎麼走；再改回來，**只改副程式裡一處**，
主程式一個字都不用動。

### 53：一個參數

等待和停車都收進副程式了。練習：呼叫 `前進(500)`、`前進(2000)` 比較距離；
自己加一個 `右轉(毫秒)`。

### 54：兩個參數與轉向

| 呼叫 | 效果 |
|------|------|
| `開車(50, 50)` | 兩輪一樣快，直走 |
| `開車(20, 60)` | 左輪慢、右輪快，往左彎 |
| `開車(60, 20)` | 左輪快、右輪慢，往右彎 |
| `開車(50, -50)` | 一正一負，原地右轉 |

動力範圍 −100～100，**負數代表倒退**。（只有「動力放變數」時才能是負的；
積木上直接填的固定數字只能 0–100，倒退要改方向下拉選單。）
練習：做出「原地左轉」、「倒退直走」。

### 55：走正方形

`走正方形` = 重複 4 次 { `前進(800)`、`右轉(400)` }。
**右轉 400 毫秒是不是剛好 90°？只有你的真車知道。** 地板、電池電量、輪胎都會影響，
請在真車上調這個時間，直到轉出來接近直角。練習：改成走三角形（轉角要多少？）、
走更大的正方形。

### 56：自動閃避

loop 裡每圈量距離：太近就呼叫 `閃避`（後退、原地右轉、停），否則 `開車(50, 50)`。
要改後退多久、轉多少，只改 `閃避` 裡面。練習：改成遇到障礙往左閃；把 20 cm 改大改小。

## 在積木頁怎麼做

1. 點左邊分類 **副程式**，拉出「副程式 我的副程式」積木，點名字改成「前進」。
2. 要加參數：點積木左上角的 **齒輪**，把「輸入」拖進右邊，點它改名（例如「毫秒」）。
3. 把要重複的積木放進副程式裡；用到參數的地方，從 **變數** 分類拉「毫秒」積木。
4. 回到 **副程式** 分類，會多出一個「前進」的呼叫積木，拉到 setup 或 loop 裡。
   有參數的呼叫積木右邊會有空格，把數字積木接上去。

## 常見錯誤

- **忘了呼叫**：只有定義，車子完全不動。
- **參數順序錯**：`開車(左輪, 右輪)` 填成（右, 左），車子往反方向轉。
- **自己呼叫自己**：副程式不能呼叫自己（直接或繞一圈都不行），送出時會被拒絕。
- **參數是全域變數**：參數名字不要和主程式自己建立的變數同名，
  不然呼叫副程式時會把主程式的變數蓋掉。副程式結束後參數也還留著最後的值。
- **轉向時間沒調**：55 的 400 毫秒只是舉例，要在真車上調。
- **層數太多**：if、迴圈、每一層呼叫都算一層，合計最多 8 層。
- 呼叫放在 setup 只會跑一次；放在 loop 才會一直重複。

## 小結

副程式讓程式「先取名字，再組合」：定義寫一次、呼叫用很多次；
參數讓同一個副程式能做不同大小的事；副程式可以組合成更大的副程式。
