# Blockly 板 I²C 六路輸出範例

範例選單 → F「對外 I2C」：43～46 為 M1～M4，47～48 為 S1～S2，49 為六路整合。
使用 esp32dev_i2c；位址 0x36，SDA GPIO21、SCL GPIO22、GND 共地。
控制的是 Blockly 板本身，並非另一塊麥輪底盤。

## 功能編號

各單路範例使用功能 0。整合版：0=M1、1=M2、2=M3、3=M4、4=S1、5=S2。
所有功能皆為可回讀的類比數值；回讀的是命令值，不是馬達轉速或舵機位置感測值。
馬達 -100～100（PWM 百分比）：正值正轉、負值反轉、0 停止；超限會限制至範圍內。
舵機 0～180 度；超限會限制至範圍內。

## 執行

1. 載入範例，確認本板端子與機構。
2. 執行會停止本板所有馬達；此範例使用的舵機會移至 90 度。
3. 主機以既有 CMD_FUNC_SET 0x65 寫入功能值：`[0x65, idx, value_hi, value_lo]`，有號 int16、大端序。
4. loop 每 50ms 套用各輸出；重新執行會重設功能值（馬達 0、舵機 90）。
5. 若需要開機執行，使用既有保存／自動執行功能；只載入範例不等於已存檔或已執行。

例如整合版功能 0 寫入 -30：`65 00 FF E2`；功能 4 寫入 90：`65 04 00 5A`。
最新版 MecanumFlasher_Dynamic.exe 主控已整合 /dash.html 可配置手機控制面板與功能寫入。預設 Blockly 六路頁對應範例 49；單路範例使用功能 0，需自行修改綁定。
範例不含斷線逾時停機：主機停止送值後仍保留最後命令，不適合當作失聯停機機制。
