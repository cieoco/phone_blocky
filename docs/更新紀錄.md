# ESP32 Phone Blocky 更新紀錄

## 2026年10月10日 更新

### 📱 積木頁改成手機用的固定版面（app shell）

**需 `uploadfs`。** 整頁不再上下捲動，固定分成四條：頂列（看全部／整理／☰ 選單）、
積木工作區、訊息列、底列（停止／執行）。

- 舊版是長頁面、積木區只是中間一個固定高度的視窗，結果頁面和積木畫布**兩層都會捲**，
  手指在畫布邊緣一拖，瀏覽器分不出要平移畫布還是捲頁面；而且一捲頁面，正在編輯的
  工作區就有一半移出螢幕。現在唯一會動的只有畫布。
- 新增 **⤢ 看全部**：一下把整支程式縮到剛好塞滿畫面（`zoomToFit`），直接解決
  手機上「看不到全部」。另有 **⇅ 整理積木**：排成一直欄後自動看全部。
- **兩指縮放本來就能用**，只是沒人知道（Blockly 的 `pinch` 預設跟著 `wheel`／`controls` 開）。
  另外加上 `maxScale 2.0` / `minScale 0.3` 護欄，否則「看全部」在程式只有兩三個積木時
  會放大到離譜、程式很長時又縮到看不見字。
- **執行／停止移到底列**（手機上拇指最好按的位置，而且編輯時永遠看得到）。
- **系統訊息收成底部一行**，只顯示最新一條，點一下展開完整面板。錯誤訊息要在編輯時
  就看得到才有用，所以它固定在畫面內、不會被捲走。
- 存檔／開啟／開機自動執行／Plotter／回首頁收進 **☰** 選單（底部面板）。這些是偶發操作，
  不該在編輯時佔掉垂直空間；檔案操作按完選單會自動收起，免得結果訊息被蓋住。
- 桌機維持原本「藍底 + 白卡」外觀，只是改成滿高不捲動。

> 手機上寫大程式仍然會擠，那是 390px 寬螢幕的物理限制。建議手機當現場操作與微調的
> 介面，大程式在平板或電腦上寫完「下載到本機」存成 `.xml` 再帶過來。

### 📶 WiFi 設定：存不進去不再偽裝成存好了

**需重新燒錄韌體並 `uploadfs`。**

- `/setwifi` 的每個 NVS 寫入都會驗證，失敗回報失敗並**明講哪一步失敗、而且不重開機**。
  舊版寫入失敗也回「已儲存」然後重開，等於把「設定沒存進去」偽裝成「存好了但連不上」，
  這兩種情況在畫面上完全無法分辨。
- 新增 `GET /api/wifi`：已存 SSID、密碼長度（不回密碼）、連線狀態與**中文原因**、
  IP／訊號／channel、下次重試倒數、AP 名稱與連線數。`set.html` 頁首會顯示並每 5 秒更新。
  最關鍵的是狀態碼：**1 = 掃不到這個 SSID**（名稱打錯，或那是 5GHz——ESP32 只有 2.4GHz）、
  **4 = 掃到了但關聯失敗**（幾乎都是密碼錯）。
- **STA 背景自動重連**，退避 5→10→20→40→60 秒。舊版開機只試一次 10 秒，失敗就永遠
  停在 AP-only，路由器比板子晚開機就中獎。
- AP + STA 都有時，**AP 名稱改成精簡格式**：`243C-192.168.0.12`（原本
  `ESP32-243C (192.168.0.12)` 在手機 WiFi 清單裡會被截掉尾巴，而被截掉的正好是 IP）。
  自訂的控制板名稱不會被換成 MAC，只改用同樣精簡的分隔。另外守住 SSID 的 32 bytes
  上限並在 UTF-8 字元邊界截斷——超過會讓 `softAP()` 直接失敗、AP 整個不見。
- 修正「只存 WiFi」會把控制板名稱清空：名稱欄位是 `display:none` 而不是 `disabled`，
  瀏覽器照樣會送出 `name=""`，而舊版無條件寫入。
- 設定頁的重開機改成延遲執行，不再在 AsyncWebServer 的 callback 裡 `delay` + 重開
  （那會卡住 AsyncTCP、回應常常還沒送完就被切斷）。

### 🔧 從機韌體的 JSON 巢狀上限掉回 10（已修）

`platformio.ini` 的 `[env:esp32dev_i2c]` 覆寫了 `[env]` 的 `build_flags`，
`-DARDUINOJSON_DEFAULT_NESTING_LIMIT=32` 在從機韌體裡整個消失，巢狀上限掉回
ArduinoJson 預設的 10（只夠 3 層積木）。症狀是**同一支程式在桌上模式跑得好、
燒成從機版就解析失敗**。已補上 `${env.build_flags}`。

## 2026年10月9日 更新

### 🔁 Blockly 支援迴圈與多層巢狀

- 「流程控制」新增 **重複 N 次**、**當條件成立時重複／重複直到條件成立** 兩種積木。
- 如果／重複／當…重複 可互相包，**最多 8 層**（原本「如果」實際只能包 3 層，第 4 層會整支程式解析失敗）。
- 超過 8 層時網頁直接提示「積木巢狀太深」，不送出；韌體也會回 `nesting_too_deep`，不再是看不懂的 `json_parse_failed`。
- 迴圈裡的指令連續執行，需要間隔請自己加延遲；按「停止」可隨時中止，含永不結束的迴圈。迴圈中 M3/M4 角度保持照常運作。
- 韌體：`platformio.ini` 放寬 ArduinoJson 解析深度（10 → 32）；`jsonTask` 堆疊 8 KB → 12 KB。**需重新燒錄韌體並 uploadfs。**
- AI 自然語言產生程式暫不使用迴圈。

### 🔢 數值插槽、且／或、不再默默略過積木

- 馬達動力、轉速、移動／旋轉角度、舵機角度、延遲毫秒改成**可接積木的插槽**：放數字和以前一樣，也可以放變數、感測器或算式，例如「舵機角度 = i × 10」。超出範圍時韌體自動夾限（動力 ±100、舵機 0–180）。
- **舊存檔不用重做**：開啟舊程式時，原本填的數字會自動變成插槽裡的數字積木，產生的指令和以前完全相同。
- 「邏輯」新增 **且／或** 積木，可寫「超音波 < 20 且 按鈕按下」。
- 沒接在 setup／loop 裡的積木，執行或存檔時會提示「有 N 個積木不會執行」；不支援的積木會直接報錯，不再默默略過。
- 刪除舊版「馬達」「舵機」積木（功能與馬達模組的新積木重複）。含這兩個積木的舊存檔將無法開啟。

### 📁 存檔分成 ESP32 與本機

- 「程式操作」改成兩組四個按鈕：**存到 ESP32／從 ESP32 開啟**、**下載到本機／從本機開啟**。
- 新增「從本機開啟」：以前下載的備份檔打不回來，現在電腦和手機都能選 .xml 檔載入。
- 下載可自訂檔名；修正 iPhone Safari／Firefox 可能下載失敗的問題。
- 畫面有未存修改時開啟前會確認；要覆蓋 ESP32 上別的程式時會先提醒。開啟失敗時畫面上的積木保持不變。

### 💾 修正存檔

- **問題**：約 30 個積木以上的程式「存檔後讀回驗證失敗」或無法開啟；再大一點直接 `bad json: NoMemory`。
  原因是韌體讀回時把 XML 塞進固定 8 KB 的緩衝（XML 被默默丟掉），存檔解析也只多留 1 KB；
  而且預設 NVS 只有 20 KB，單筆上限約 8 KB。
- **修正**：
  - 存檔／讀回改成不經固定大小緩衝，資料原樣存、原樣讀回（前端讀回後逐字比對 XML）。
  - 新增 128 KB 的程式專用儲存區（flash 末端未使用的空間），舊存檔與「開機自動執行」設定第一次開機時自動搬過去；WiFi、PID 設定與網頁檔都不受影響。
  - XML 不再存積木 ID，約小 20%。
  - 上限改為 32 KB（約 140 個動作積木）；超過時存檔前就會提示，錯誤訊息改成中文。
- **需要重新燒錄韌體**（`pio run --target upload` 會一併寫入新的分割表），網頁也要 `uploadfs`。

### 🧩 副程式

- 新增「副程式」分類：把一段積木包成副程式（可加參數，例如「夾爪（角度）」），再用呼叫積木重複使用。
- 副程式可以呼叫其他副程式，但不能直接或間接呼叫自己；呼叫算一層，和如果／迴圈合計最多 8 層。
- 暫不支援有回傳值的副程式。
- 被停用（右鍵「停用積木」）的積木不會執行。

### 🧮 數學積木加強

- 運算積木新增 **餘數**，符號改成 + − × ÷。
- 新增 **絕對值**、**隨機整數 從…到…**、**限制…在…到…之間**、**對應換算**（原範圍 → 新範圍，例如距離 0–100 cm → 舵機 0–180°）。
- 運算、比較積木的插槽沒放東西時會直接提示，不再默默當成 0。
- 仍是整數運算（÷ 捨去小數）。

## 2026年6月16日 更新

### 🤖 馬達調校工具：自動估速度 PID 全面修正

#### ✅ 修正錯誤的 PID 增益（主因）
- 自動估算出的 Kp/Ki 因「duty 分數 vs 百分比」單位不一致而**小了 100 倍**，PID 形同失效（純 PID 收斂要 >10 秒）。
- 換算成百分比單位後對齊韌體輸出，閉迴路收斂恢復正常。

#### ✅ 量測精度
- 新增韌體 **50Hz 高速擷取緩存**（`chart_buffer_start/stop`），取代 10Hz telemetry，能解析馬達上升段。
- τ 改用第一個「從 0 起步」的準位段估計，避免落在 0.05s 地板值。

#### ✅ 前饋與速度環
- kS 允許小負截距，前饋不再於目標轉速處系統性偏高。
- 韌體速度環加入**目標斜坡、積分抗飽和、前饋非負夾**（移植自 motorControl）。
- 自動估完成後前饋自動套用 RAM。

#### ✅ 安裝相依
- 放寬 `numpy` 版本上限（移除 `<2.0`）、`matplotlib>=3.9`，Python 3.13 可直接安裝、不需 C 編譯器。

#### 📄 文件
- 重寫 [安裝教程](安裝教程.md)：依實際工具更新「開啟調校工具 / 燒錄韌體 / 自動估 PID」流程（含 Baud、斷線後燒錄、清除 flash 等）。
- 同步更新 [motor_tuner 說明](../motor_tuner/README.md)：補上「燒錄」分頁與「自動估 PID」功能。
