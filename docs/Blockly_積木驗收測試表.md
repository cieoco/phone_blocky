# Blockly 積木驗收測試表

此表只涵蓋 `data/blockly.html` **目前工具箱可見**的積木。`repeat`、`while/until`、`pinMode` 等未曝光積木不在本輪驗收範圍。

日常驗證可先使用 [Blockly 自動驗證頁](../data/blockly_test.html)：它會自動檢查連線、NVS API、超音波、變數／算術／if 與 Plot 資料格式；馬達與舵機仍依本表進行安全的實機驗收。

## 使用方式

1. 更新韌體與 LittleFS，開啟 Blockly 頁面。
2. 每次只放入表中指定的「最小程式」，避免多個功能互相影響。
3. 靜態欄確認瀏覽器 Console 沒有「沒有對應的翻譯器」，並可在 WebSocket 或序列除錯看到預期 JSON。
4. 實機欄確認實際硬體、系統訊息或獨立 Plotter 的結果。
5. 填入日期、板子與失敗現象；失敗時優先記錄停在 Blockly、JSON、韌體回覆或硬體哪一層。

狀態代號：`⬜ 未測`、`✅ 通過`、`❌ 失敗`、`⚠️ 受硬體條件限制`。
