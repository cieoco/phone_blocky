## 迴圈決策與相容性

使用者同意依直譯器可行性決定：現有排程每次一條頂層命令，巢狀分支同步執行，沒有可暫停／恢復的迴圈堆疊。這次移除 AI 的 while/until 能力；Blockly 工具箱原本就未展示 repeat/while/until，保留定義僅為讀取舊 XML，翻譯時明確報錯。韌體拒絕含未知動作的整份新程式，原程式不被部分覆蓋。持續判斷改用 loop + if。

保留舊 command:motor_control/servo_control、字串數字欄位、delayTime、arduino_setup/loop 包裝。舊 XML 的延遲文字不會在載入時被欄位上限靜默截短；超過新輸出 10000ms 上限會提示拆分。AI 驗證是有限子集，Blockly 的變數／算術／列印另列於 schema，沒有為了通過 AI 驗證而刪除。

- `python -m unittest discover -s tests -v`：4 組通過，涵蓋前端/relay 同一批正反案例、提示詞及範例、硬體元資料、relay validate/generate 處理（模型回應以 mock 代替，無網路呼叫）。本機使用 `.venv-check/Scripts/python`，依 `ai-relay/requirements.txt` 建立隔離環境。
