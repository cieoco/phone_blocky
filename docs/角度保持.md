# 角度保持（M3/M4 角度模式）作法說明

本文件說明 joy.html 角度模式下，M3/M4 馬達「移動到指定角度並維持」的實作方式，
以及開發過程踩到的關鍵問題與修法。對應韌體：[src/CommandProcessor.h](../src/CommandProcessor.h)。

> 核心觀念：**角度保持是韌體的閉迴路（伺服）行為，不需要馬驅板（L293D）的硬體保持功能。**
> 板子只負責 PWM，韌體用編碼器回授持續把軸推回目標，就是伺服機的原理。

---

## 一、資料流（前端 → 韌體）

```
joy.html 角度滑桿 (ActionSliderFun_Angle_M3)
  → 只更新變數 vM3AngleValue（不直接送指令）
  → 每 200ms 的 joy 封包夾帶 M3A / M4A
WebSocket → CommandProcessor::processCommands (mode:"joy")
  → updateJoyPositionTarget()              ← 設定目標、啟動移動
  → startMotorPositionMove(..., hold=true)  ← joy 角度模式帶 hold=true
main loop → updateAngleControl()            ← 持續跑閉迴路（驅動 + 保持）
```

**保持的前提條件**：`Action3==2`（角度模式）且 `Button1==1`（M3 虛擬按鈕 ON）。
任一不成立 → 停止並退出保持。M4 對應 `Action4` / `Button2`。

---

## 二、狀態機（三個階段）

```
DRIVE（移動到目標）
  ├─ 樂高模式 updateMotorPositionMoveLego（查表 + 煞車/沉降相位）
  └─ 一般模式 updateMotorPositionMovePID（PID）
        │ 任何結束方式（到位 / 失速 / 逾時）都走這裡
        ▼
  finishOrHoldPosition()
        ├─ hold=false（內部失敗保險等）           → stopMotorRuntime（停止）
        └─ hold=true （joy 角度模式 / move_to / move_by）→ 進入 HOLD 階段
        ▼
HOLD（角度保持）→ updateMotorPositionHold()
```

樂高與一般（HALL/PID）兩種馬達**共用** HOLD 邏輯：派發點在 `updateMotorPositionMove`
最前面攔截 `POSITION_PHASE_HOLD`，與控制模式無關。

---

## 三、HOLD 控制律：主動伺服 P + 積分創爬 + 遲滯

```
出力 duty = MIN_DUTY + GAIN×|誤差| + KI×|積分|      （限幅 MIN ~ MAX）
```

- **P（比例）**：誤差越大、出力越大。
- **I（積分創爬）**：卡住推不動時積分持續累加，慢慢把力道頂到能破靜摩擦，再把軸推進目標。
  解決「小誤差出力不足以破 L293D 壓降＋減速箱靜摩擦 → 卡在 1~2° 持續通電卻推不動」的死角。
- **遲滯死區**：進 `SETTLE` 內 → 放鬆並歸零積分；放鬆後須偏離超過 `REENGAGE` 才重新出力
  → 死區邊緣不來回抖動。
- **anti-windup 三道**：進 settle 歸零、誤差換邊（跨越目標）歸零、積分限幅至上限 duty。

## 四、開發過程的三個關鍵坑（皆已修正）

| # | 症狀 | 根因 | 修法 |
|---|------|------|------|
| 1 | 保持時有時無 | 只有「乾淨到位」會進 HOLD，**失速/逾時直接停**不進 HOLD | 失速/逾時分支改走 `finishOrHoldPosition` |
| 2 | 保持時有時無（真根因） | `setMotorDuty` 在 duty==0 時把 mode 打成 idle，而迴路閘門是 `mode==POSITION`，控制器一吐 0 就被永久鎖死 | duty==0 時**位置/速度模式保留 mode**，只有 PWM 直控的 0 才 idle |
| 3 | 1kHz 嗡聲 vs 沒保持力 | 提高 PWM 頻率（20k/10k）→ L293D 低 duty 扭力大幅縮水 → 保持沒力 | 維持 **1 kHz**（完整扭力，接受嗡聲）；頻率設定在 [lib/AFMotor/src/AFMotor.h](../lib/AFMotor/src/AFMotor.h) `DC_MOTOR_PWM_RATE` |

> 坑 #2 的通則：`setMotorDuty(duty=0)` 同時被用於「停止並 idle」與「閉迴路瞬間輸出 0 但仍在控制」
> 兩種語意，必須區分。閉迴路輸出 0 時不可改變其控制模式。

## 五、可調參數

**可即時調整（set.html / WebSocket，存 NVS）** — 變數定義在 [src/CommandProcessor.h](../src/CommandProcessor.h)，預設值在 [include/config.h](../include/config.h)：

| 參數 | 預設 | 作用 |
|------|------|------|
| `holdSettleDeg` | 1.5° | 進此誤差內 → 放鬆、歸零積分（死區） |
| `holdKi` | 8.0 | I：卡住時的創爬速率（收斂慢↑、頂過頭↓） |
| `holdMaxDuty` | 60 | 夾持力上限 PWM% |

**程式內固定常數**（[src/CommandProcessor.h](../src/CommandProcessor.h) `constexpr`，不可即時調）：

| 常數 | 值 | 作用 |
|------|-----|------|
| `POSITION_HOLD_REENGAGE_MARGIN` | 1.0° | 重啟門檻 = `holdSettleDeg` + 此邊際（遲滯） |
| `POSITION_HOLD_MIN_DUTY` | 18 | 出力下限 |
| `POSITION_HOLD_GAIN` | 3.0 | P：每度誤差增加的 duty |

**調校手感**：
- 收斂太慢（殘留誤差收不掉）→ 調高 `holdKi`。
- 收斂時頂過頭 / 獵動 → 調低 `holdKi`，或加大 `holdSettleDeg`（連帶把重啟門檻一起拉開）。
- 邊緣嗡聲想更安靜（願意放寬精度）→ 加大 `holdSettleDeg` 死區。

## 六、注意事項

- **持續發熱/耗電**：主動保持頂著外力時持續通電（最高 60% duty），長時間頂死會發熱。
  若需要可另加「保持逾時自動釋放」保險。
- **move_to / move_by 也會保持**：`move_to` / `move_by`（Blockly、PROG、直接 cmd）的 `hold=true`，
  到位後與 joy 角度模式同樣進入 HOLD 持續保持角度。要解除保持，對該馬達下 `stop`
  （或 `pwm` / `speed` 切換模式）。loop 不會因此卡死——排程不靠 mode 回到 idle 來推進。
